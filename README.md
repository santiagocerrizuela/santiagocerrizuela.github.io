# Santiago Cerrizuela, PhD

Personal website of Santiago Cerrizuela, staff scientist in the Division of Molecular Neurobiology at the German Cancer Research Center (DKFZ), Heidelberg.

**Live site:** [santiagocerrizuela.github.io](https://santiagocerrizuela.github.io)

## About

I'm an Argentinian biochemist working on single-cell multiomics of the stem cell populations in the subventricular zone, the main neurogenic niche of the adult mouse brain. I optimized **HT-scNMT** (high-throughput single-cell nucleosome occupancy, methylome and transcriptome), a protocol that profiles chromatin accessibility, DNA methylation and gene expression from the same single cell.

I have also edited several books. Outside the lab I run [TROTAMUNDO](https://www.youtube.com/Santiagocerrizuela), a YouTube travel channel, and I play padel and table tennis.

## Updating the site

1. Open `index.html` in this repository and click the pencil icon to edit.
2. Change the text you want. To add a publication, position or book, copy an existing `<article class="entry">` block and edit its contents.
3. Click **Commit changes**. The live site updates within a minute or two.

To replace the photo, upload a new image named `photo.jpg`; it overwrites the old one.
